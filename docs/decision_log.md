| 2026-10-11 | Sonnet caps **60 steps / $1.00** (not the p90 rule's 20 / $0.25) | Calibration (60 trials, 44 passing): passing p90 17.7 steps / $0.23, max 52 / $0.48; failing max $0.98. The p90 rule would truncate 5 passing runs and act as an abandon policy itself; 100 / $3 would push G2's threshold (0.4 × max_steps) to step 40, which only 3/60 runs reached, disabling abandon. 60 / $1 sits above every observed run (costliest calibration run: $0.98), so in practice the step cap and Harbor's timeout bind first. Harbor's per-task agent timeout (≤ 60 min) remains the binding limit for long tasks |
| 2026-10-11 | Excluded `break-filter-js-from-html` (manual, `tasks/exclusions.yaml`) | Sonnet 5.5 refuses on the first turn (`finish_reason: content_filter`) every time; no controller can affect it. Refusals now end trials as `model_refusal` and `finish_reason` is logged on every call |
| 2026-10-11 | Verification heuristic widened before dev: running a script file (`python x.py`, `perl x.pl`, …), `go/cargo run`, `make … test/check/testsuite`; edits and checks are ordered within a single command | With the original regex `verified_after_last_edit` was false at all 54 calibration finishes (Sonnet verifies by running its program, often in the same command as the edit).
